# Getting help

- **How a field or a message works:** read [docs/protocol.md](docs/protocol.md) and the schemas in
  [schema/](schema).
- **A setup problem:** see the troubleshooting table in the [README](README.md#troubleshooting).
- **A bug or a feature request:** open an issue with the templates. Do not paste keys, tokens or
  private URLs.
- **A security problem:** do not open an issue. Follow [SECURITY.md](SECURITY.md).

This is a small project maintained in spare time. There is no guaranteed response time.
